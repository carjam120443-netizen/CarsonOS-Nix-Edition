# CarsonOS Nix Edition

A NixOS-based Linux distribution project from [Carson](https://github.com/carjam120443-netizen).

CarsonOS Nix Edition starts with a reproducible NixOS live ISO and a declarative system configuration. The goal is to build a polished, beginner-friendly desktop operating system while keeping the reliability and rollback capabilities of NixOS.

> **Project status:** Early development. The initial configuration is a starting point, not a finished or production-ready operating system.

## Current foundation

- **Base:** NixOS (nixpkgs unstable)
- **Architecture:** x86_64
- **Desktop:** KDE Plasma 6
- **Optional window manager:** i3 (selectable from the SDDM login screen)
- **Installer:** Calamares graphical installer (NixOS installer integration)
- **Display manager:** SDDM
- **Init/system manager:** systemd (NixOS default)
- **Networking:** NetworkManager
- **Debian/Ubuntu compatibility:** Distrobox + Podman containers (APT runs inside containers, not on the NixOS host)
- **Audio:** PipeWire
- **Package management:** Lix (Nix-compatible implementation), with `pkg` as an alias for `nix`
- **Text editor:** Textadept
- **Version control:** Git
- **GNU utilities:** GNU grep
- **Shell tools:** Zsh with Deer file navigation, plus CMatrix terminal animation
- **Build definition:** Nix flake
- **CI:** GitHub Actions ISO build

## Build the ISO

You need Nix with flakes enabled on an x86_64 Linux machine.

1. Clone the repository:

   ```bash
   git clone https://github.com/carjam120443-netizen/CarsonOS-Nix-Edition.git
   cd CarsonOS-Nix-Edition
   ```

2. Generate and commit the lock file so builds use pinned dependencies:

   ```bash
   nix flake lock
   ```

3. Build the ISO:

   ```bash
   nix build .#nixosConfigurations.carsonos-iso.config.system.build.isoImage
   ```

The ISO will be in `result/iso/`. Test it in a virtual machine before trying it on physical hardware.

The live ISO uses the official NixOS graphical Calamares installer module. It provides a graphical installation flow, including disk and partition selection. The current integration is the standard NixOS Calamares workflow; it has not yet been customized to automatically deploy this repository's exact CarsonOS flake configuration. Review the generated installation configuration before installing, and test in a VM first.

## GNU grep and Debian/Ubuntu compatibility

GNU grep is included as the `gnugrep` package.

CarsonOS also includes Distrobox and Podman for users who need a Debian or Ubuntu environment. APT and dpkg should run **inside** that container, not against the CarsonOS host. For example, after booting CarsonOS:

```bash
distrobox create --name debian --image debian:stable
distrobox enter debian
sudo apt update
sudo apt install <package-name>
```

You can use an Ubuntu image instead by replacing `debian:stable` with an Ubuntu image such as `ubuntu:24.04`. The container keeps Debian/Ubuntu package management separate from the NixOS host, whose system packages remain managed declaratively with Nix/Lix. The host does not use Debian or Ubuntu `sources.list` files.

## System information fetch tools

CarsonOS includes several alternative system-information tools alongside Fastfetch:

- [fetchutils](https://search.nixos.org/packages?channel=26.05&query=fetch#show=fetchutils) — collection of small shell utilities for fetching system information.
- [cpufetch](https://search.nixos.org/packages?channel=26.05&query=fetch#show=cpufetch) — displays CPU architecture information.
- [ufetch](https://search.nixos.org/packages?channel=26.05&query=fetch#show=ufetch) — tiny system information display.
- [nerdfetch](https://search.nixos.org/packages?channel=26.05&query=fetch#show=nerdfetch) — POSIX system-information fetch script that uses Nerd Fonts.
- [pridefetch](https://search.nixos.org/packages?channel=26.05&query=fetch#show=pridefetch) — a colorful pride-themed fetch display.
- [pridecat](https://search.nixos.org/packages?channel=26.05&query=pride#show=pridecat) — a pride-themed terminal utility.
- [fetch](https://search.nixos.org/packages?channel=unstable&query=fetch#show=fetch) — the `fetch` package from the unstable Nixpkgs channel.
- [ramfetch](https://search.nixos.org/packages?channel=26.05&query=fetch#show=ramfetch) — displays RAM and memory information.
- [honeyfetch](https://search.nixos.org/packages?channel=26.05&from=50&query=fetch#show=honeyfetch) — a classic Neofetch-style system information display.
- [countryfetch](https://search.nixos.org/packages?channel=unstable&query=fetch#show=countryfetch) — a country-themed system-information display.
- [gpufetch](https://search.nixos.org/packages?channel=unstable&query=fetch#show=gpufetch) — displays GPU information.
- [zigfetch](https://search.nixos.org/packages?channel=unstable&query=fetch#show=zigfetch) — another lightweight system-information fetch tool.

These are installed as alternatives; run the command matching the tool you want to use.

## Privilege escalation and font tools

- [doas](https://search.nixos.org/packages?channel=unstable&query=doas#show=doas) — a lightweight alternative to `sudo`. The package is installed, but CarsonOS does not switch its privilege-escalation configuration to doas automatically; `sudo` remains the configured default unless you explicitly configure doas.
- [fontconfig](https://search.nixos.org/packages?channel=unstable&query=font#show=fontconfig) — font configuration and discovery library used by applications to locate and match fonts.
- [font-manager](https://search.nixos.org/packages?channel=unstable&query=font#show=font-manager) — graphical font management application.
- [font-adobe-75dpi](https://search.nixos.org/packages?channel=unstable&query=font#show=font-adobe-75dpi) — legacy Adobe 75-DPI X11 bitmap fonts.

## Git package variants

CarsonOS selects the feature-complete `gitFull` package by default through the NixOS `programs.git.package` option. Regardless of the selected package variant, the command users run is simply `git`. The three Nixpkgs variants are alternatives, not separate commands to install side-by-side:

- `pkgs.git`: standard Git package.
- `pkgs.gitFull`: feature-complete build with optional integrations and GUI tools such as `gitk` and `git gui`.
- `pkgs.gitMinimal`: smaller build with some optional features omitted.

Only one variant is selected for the system to avoid overlapping files and duplicate Git executables. To switch, edit the `package` line in `configuration.nix`, for example:

```nix
programs.git.package = pkgs.gitMinimal;
```

or:

```nix
programs.git.package = pkgs.git;
```

## Lix

CarsonOS uses the stable Lix package from nixpkgs as its Nix implementation. Lix is compatible with the Nix ecosystem, so existing Nix commands and flakes remain the normal way to manage the system.

After booting, verify the implementation with:

```bash
nix --version
```

The output should identify itself as **Lix**.

CarsonOS also provides `pkg` as a shell alias for `nix`, so commands such as `pkg profile list` work as a shortcut. The original `nix` command remains available; both names use the same Lix-backed Nix interface.

## GitHub Actions

The **Build CarsonOS Nix Edition ISO** workflow runs when relevant configuration files change on `main`, or when manually started from the Actions tab. The resulting ISO is uploaded as a workflow artifact.
