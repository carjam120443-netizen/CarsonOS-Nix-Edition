# CarsonOS Nix Edition

A NixOS-based Linux distribution project from [Carson](https://github.com/carjam120443-netizen).

CarsonOS Nix Edition starts with a reproducible NixOS live ISO and a declarative system configuration. The goal is to build a polished, beginner-friendly desktop operating system while keeping the reliability and rollback capabilities of NixOS.

> **Project status:** Early development. The initial configuration is a starting point, not a finished or production-ready operating system.

## Current foundation

- **Base:** NixOS (nixpkgs unstable)
- **Architecture:** x86_64
- **Desktop:** KDE Plasma 6
- **Optional window manager:** i3 (selectable from the SDDM login screen)
- **Installer:** Calamares graphical installer (NixOS installer integration)
- **Display manager:** SDDM
- **Init/system manager:** systemd (NixOS default)
- **Networking:** NetworkManager
- **Audio:** PipeWire
- **Package management:** Lix (Nix-compatible implementation)
- **Text editor:** Textadept
- **Build definition:** Nix flake
- **CI:** GitHub Actions ISO build

## Build the ISO

You need Nix with flakes enabled on an x86_64 Linux machine.

1. Clone the repository:

   ```bash
   git clone https://github.com/carjam120443-netizen/CarsonOS-Nix-Edition.git
   cd CarsonOS-Nix-Edition
   ```

2. Generate and commit the lock file so builds use pinned dependencies:

   ```bash
   nix flake lock
   ```

3. Build the ISO:

   ```bash
   nix build .#nixosConfigurations.carsonos-iso.config.system.build.isoImage
   ```

The ISO will be in `result/iso/`. Test it in a virtual machine before trying it on physical hardware.

The live ISO uses the official NixOS graphical Calamares installer module. It provides a graphical installation flow, including disk and partition selection. The current integration is the standard NixOS Calamares workflow; it has not yet been customized to automatically deploy this repository's exact CarsonOS flake configuration. Review the generated installation configuration before installing, and test in a VM first.

## Lix

CarsonOS uses the stable Lix package from nixpkgs as its Nix implementation. Lix is compatible with the Nix ecosystem, so existing Nix commands and flakes remain the normal way to manage the system.

After booting, verify the implementation with:

```bash
nix --version
```

The output should identify itself as **Lix**.

## GitHub Actions

The **Build CarsonOS Nix Edition ISO** workflow runs when relevant configuration files change on `main`, or when manually started from the Actions tab. The resulting ISO is uploaded as a workflow artifact.
